# لوحة تحكم الأستاذة شيماء العباسي

نسخة GitHub Pages جاهزة للنشر.

## الملفات
- `index.html` — الواجهة الرئيسية
- `teacher.css` — التنسيقات
- `teacher.js` — وظائف لوحة التحكم
- `.nojekyll` — لضمان نشر الملفات الثابتة كما هي

## ملاحظة مهمة
هذه النسخة تعمل كواجهة Static وتخزن البيانات في `localStorage` داخل متصفح كل مستخدم.
لذلك البيانات ليست مشتركة بين الأجهزة، ولا تعتبر حماية تسجيل الدخول آمنة.
عند ربطها بـ Django Backend يجب نقل المصادقة والبيانات إلى الـBackend.
